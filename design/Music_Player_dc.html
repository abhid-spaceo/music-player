2Streaming-app conventions applied to 1a

What I took, and what I didn't

I've borrowed the interaction conventions your friends already have muscle memory for — the affordances that are common to every mainstream player — and left the visual identity alone, since copying another product's look would undo the direction and isn't something I'll reproduce. Added here: a search affordance in the header rather than only in the tab bar, a play-all / shuffle action row, a per-row overflow menu (⋮, 44px) for queue and download actions, an animated equaliser over the artwork of the playing row, an explicit downloaded pill instead of a bare tick, and skip-next on the mini-player.

Deliberately not borrowed: a home feed, recommendation shelves, "made for you" rows, or a promoted-content slot. 2b keeps one idea from that family — the recent-items grid at the top — because for a returning user it is genuinely the shortest path back to what they were listening to yesterday.

1Direction + library screen · 390px

Direction

The library is a timetable, not a storefront: a dense, hairline-ruled index of things you already own, set in a neutral grotesque with monospaced figures so durations and counts line up in columns you can scan without reading. Everything that isn't information is removed — no cards, no shadows, no rounded chrome, no gradient — so the only colour in the interface is the single amber signal that marks what is playing right now.

References: Swiss railway timetable printing (tabular density, hairline rules, tiny caps column labels, right-aligned figures) and ECM Records sleeves of the late 70s and 80s — cold neutrals, enormous negative space, type that sits still. Software touchstone: a Nakamichi cassette deck faceplate, where one amber lamp tells you the state of the machine.

Materials

Type: Instrument Sans (Google) for interface text, IBM Plex Mono (Google) for durations, counts, labels and any figure that should align. Icons: Lucide, 1.5px stroke. No photography or illustration; missing artwork is a flat field with one geometric mark.
